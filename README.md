# 🌾 Krishi Mitra: Professional Rule-Based Agricultural Expert System

**Krishi Mitra** is an intelligent rule-based expert system designed to assist farmers and agricultural enthusiasts in diagnosing crop diseases, selecting optimal fertilizers, and receiving tailored agricultural advice based on environmental parameters.

---

## ✨ Key Features
* 🔍 **Rule-Based Diagnosis:** Evaluates crop symptoms and conditions using established expert rules.
* 🌿 **Fertilizer & Soil Recommendations:** Suggests appropriate soil treatments and fertilizers.
* 📊 **Smart Decision Engine:** Provides fast and accurate agricultural decision support.

---

## 🛠️ Tech Stack & Technologies
* **Language:** Python
* **Paradigm:** Rule-Based Expert System / Artificial Intelligence
